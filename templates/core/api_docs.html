POST /api/auth/register

Register a new user account.

Request Body

{
  "username": "string",
  "email": "string",
  "password": "string"
}

Response

{
  "message": "User registered successfully",
  "user": {
    "id": 1,
    "username": "string",
    "email": "string"
  }
}

POST /api/auth/login

Authenticate and receive JWT tokens.

Request Body

{
  "username": "string",
  "password": "string"
}

Response

{
  "access": "jwt_access_token",
  "refresh": "jwt_refresh_token",
  "user": {
    "id": 1,
    "username": "string",
    "email": "string"
  }
}

GET /api/user/me

Get current authenticated user profile.

Headers

Authorization: Bearer {access_token}

Response

{
  "id": 1,
  "username": "string",
  "email": "string",
  "first_name": "string",
  "last_name": "string",
  "bio": "string",
  "created_at": "2024-01-01T00:00:00Z"
}

POST /api/resume/analyze

Upload and analyze a resume file.

Request (multipart/form-data)

resume: file (pdf, docx, txt)
role: string (optional)

Response

{
  "ats_score": 87,
  "keywords_matched": ["python", "django"],
  "keywords_total": 15,
  "skills_found": 8,
  "word_count": 450,
  "strengths": ["Strong technical skills"],
  "suggestions": ["Add more quantifiable achievements"],
  "missing_keywords": ["aws", "docker"]
}

GET /api/resume/roles

Get available job role definitions.

Response

[
  {
    "id": "python_developer",
    "name": "Python Developer",
    "keywords": ["python", "django", "flask"]
  }
]

GET /api/interview/start

Start a new interview session.

Query Parameters

role: string (required)

Response

{
  "session_id": "uuid",
  "questions": ["question1", "question2"],
  "role": "python_developer"
}

POST /api/interview/evaluate

Submit an answer for evaluation.

Request Body

{
  "session_id": "uuid",
  "question_id": 1,
  "answer": "string"
}

Response

{
  "score": 8,
  "feedback": "string",
  "strengths": ["string"],
  "improvements": ["string"]
}

POST /api/interview/summary

Get interview session summary.

Request Body

{
  "session_id": "uuid"
}

Response

{
  "total_questions": 5,
  "average_score": 7.5,
  "highest_score": 9,
  "lowest_score": 6,
  "overall_feedback": "string"
}
